# Lessons Learned

Store short, durable notes that future agents should reuse. Add a dated file only after a decision or correction is verified.

Use this shape:

```markdown
# <Lesson>

Date: <YYYY-MM-DD>
Context: <spec, plan, or implementation task>

## Decision or Correction
<What changed and why?>

## Evidence
<Test, query, review finding, or user decision.>

## Reuse
<What future agents must do or avoid.>
```

Do not use this folder for transient status, guesses, or full chat transcripts.
